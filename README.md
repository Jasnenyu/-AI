# 酸菜AI

基于节点画布的 AI 分镜工作台，一站式完成图片生成、编辑与分镜流程

## 功能特点

- 🎨 无限画布：自由拖拽的节点式工作流
- 🤖 AI 图片生成：集成多家 AI 绘画服务
- 🎬 视频生成：支持 27 个视频生成模型（PPIO/FAL/KIE）
- 📝 分镜管理：完整的分镜创作流程

## 下载
